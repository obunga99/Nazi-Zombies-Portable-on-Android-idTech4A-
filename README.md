# Nazi-Zombies-Portable-on-Android-idTech4A-FTEQW-
Play Nazi Zombies: Portable on an Android phone without a PC. The trick: build a custom libfteqw.so (the FTEQW engine with NZ:P's engine changes) inside Termux, and drop it into the already-installed idTech4A++ app using its "Load local engine library" option. idTech4A++ already provides touch controls, so nothing else needs porting.
